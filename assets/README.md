# Assets

Shared CSS and JavaScript.

## Files
- `styles.css` - Global styles
- `main.js` - Shared utilities

## Usage
```html
<link rel="stylesheet" href="../assets/styles.css">
<script src="../assets/main.js"></script>
```

## Colors
- Background: `#0d1117`
- Text: `#c9d1d9`
- Accent: `#f97316` (orange)
- Success: `#3fb950` (green)
- Border: `#30363d`
