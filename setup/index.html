Ignition Gateway Setup

One-Time Setup

Run the command below in the terminal →

1. Copy & paste this command:

curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/ignition-install.sh | sudo bash

2. Wait for installation

  1. Installing dependencies...
  2. Downloading Ignition (~200MB)
  3. Running installer...
  4. Starting Gateway...

3. Access Ignition

Once ready, open in WebVM browser:

localhost:8088

Login: admin / password

Persists in browser!

Data saved to IndexedDB. No re-install needed.

Want remote access?

Setup Tailscale to connect from any device.
