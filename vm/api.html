Ignition VM API Interface

Browser-based API for controlling and testing the VM emulator

API Endpoints

GET /api/status - Get VM status
// Example using fetch fetch('/api/status') .then(res => res.json()) .then(data => console.log(data));
POST /api/boot - Boot a VM
// Example: Boot Alpine Linux fetch('/api/boot', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ distro: 'alpine' }) });
POST /api/command - Send command to VM
// Example: Send command fetch('/api/command', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ cmd: 'uname -a' }) });

PostMessage API

For cross-origin communication with embedded VM iframe

// Send message to VM iframe const vmFrame = document.getElementById('vmFrame'); vmFrame.contentWindow.postMessage({ type: 'vm-command', action: 'boot', params: { distro: 'alpine' } }, '*'); // Listen for responses window.addEventListener('message', (event) => { if (event.data.type === 'vm-response') { console.log('VM Response:', event.data); } });
