# Screens

Perspective JSON templates and design tools.

## Modules
- `designer/` - Visual drag-drop view builder
- `sandbox/` - Interactive command terminal
- `templates/` - Component/view library

## Templates
```
templates/
├── components/  # tank, valve, pump, sensor, pipes
├── symbols/     # hopper, belt, screw
└── views/       # tank-farm, overview
```

## Usage
1. Open Designer at `/screens/designer/`
2. Drag components from palette
3. Export to JSON for Ignition
