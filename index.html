With Auth Key

Browser VM Sandbox

Run a real Linux VM directly in your browser. No installation required.

Launch VM Sandbox

Boot Alpine/Debian Linux in browser using v86 emulator

How it Works

Uses v86 (JS x86 emulator) to run real Linux. State saves to browser storage.

Available Images

Alpine Linux

~50MB, fast boot (~10s), minimal

Recommended for quick testing

Debian

~200MB, slower boot (~30s), full environment

Better for Ignition install

Buildroot

~20MB, fastest boot (~5s), ultra minimal

For basic testing only

Requirements

Modern browser with WebAssembly support (Chrome 90+, Firefox 85+, Safari 14+)

~500MB RAM available for browser tab

IndexedDB for persistent storage
