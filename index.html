🏭 Ignition Gateway - Browser Sandbox

Full Ignition 8.1 running in Debian Linux via WebAssembly | No server required

Quick Start

⚡ One-Time Setup Required

Run the command below in the WebVM terminal →

1. Copy this command:

curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/ignition-install.sh | sudo bash

2. Paste in terminal →

Right-click in the black terminal on the right and paste (Ctrl+Shift+V)

3. Wait for installation

Installation takes 3-5 minutes. You'll see:

  1. Installing dependencies...
  2. Downloading Ignition...
  3. Running installer...
  4. Starting Gateway...
  5. ✅ Ready!

4. Access Ignition

Once installation completes:

  1. Open browser inside WebVM
  2. Navigate to: localhost:8088
  3. Login: admin / password

💡 Tip: Installation only needed once. Data persists in browser cache!

Remote Access (Tailscale)

Connect to this sandbox from any device on your Tailnet:

Full Setup (Ignition + Tailscale):

curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/full-setup.sh | bash -s -- tskey-YOUR-KEY

Or add Tailscale to existing:

curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/tailscale-install.sh | bash

🔗 How it works:

1. Tailscale runs inside WebVM
2. Connects to your Tailnet
3. Access Ignition from any peer:
http://<tailscale-ip>:8088

Get auth key: Tailscale Admin

Troubleshooting

If download fails, you need to upload the Ignition installer to GitHub Releases first. See DEPLOY.md for details.
