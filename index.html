Ignition Sandbox

Commands to install Ignition SCADA on any Linux system. Copy and run in your terminal.

Quick Install

Install Ignition Gateway (Debian/Ubuntu)
curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/ignition-install.sh | sudo bash
Install Tailscale (remote access)
curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/tailscale-install.sh | bash
Full setup (Ignition + Tailscale)
curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/full-setup.sh | bash

After Installation

Access Gateway

Open http://localhost:8088
Login: admin / password

Start/Stop

/opt/ignition/ignition.sh start
/opt/ignition/ignition.sh stop

Connect Tailscale

tailscale up
tailscale ip

Check Status

/opt/ignition/ignition.sh status
tailscale status
