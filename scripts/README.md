# Scripts

Bash utilities for Konomi IgnAIte sandbox.

## Core
- `sandbox` - Main sandbox runner
- `loader` - Dynamic script loader

## System Info
- `sysinfo` - System details
- `netinfo` - Network config

## Setup
- `docker-setup` - Docker install
- `java-setup` - Java install
- `python-setup` - Python install
- `install-cli` - CLI installer
