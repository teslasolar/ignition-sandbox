Quick Commands

List commands: ./cli/sandbox-cli commands
Watch sync: ./cli/sandbox-cli watch

Command Files

JSON

{"name":"check","type":"fetch","path":"/"}

Markdown

---
name: test
type: sync
---

CSV

name,type,path
check,fetch,/
