CLI Tools

Command-line testing framework for the Ignition Sandbox

sandbox-cli

Main CLI entry point with auto-loading commands from JSON, Markdown, or CSV.

Python API ./cli/sandbox-cli status

API Wrapper

HTTP client for testing GitHub Pages endpoints with hash verification.

Python ./cli/wrappers/api-wrapper.py

MCP Tools

MCP-compatible tool definitions for external integration.

JSON MCP ./cli/sandbox-cli mcp list

Tailscale Wrapper

Tailscale CLI wrapper for status, peers, funnel, and serve.

Python Tailscale ./cli/sandbox-cli ts status

Quick Commands

Check sandbox status:

./cli/sandbox-cli ping

Check repo→pages sync:

./cli/sandbox-cli sync

List loaded commands:

./cli/sandbox-cli commands

Watch for sync after push:

./cli/sandbox-cli watch

Tailscale status:

./cli/sandbox-cli ts status

Command Files

Drop files in cli/commands/ - auto-loaded by format:

JSON

{
  "name": "my-check",
  "type": "fetch",
  "path": "index.html"
}

Markdown

---
name: my-test
type: sync
---
# Description here

CSV

name,type,path
check-1,fetch,/index.html
check-2,fetch,/setup/
