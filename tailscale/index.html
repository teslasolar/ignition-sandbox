Remote Access via Tailscale

Connect from anywhere

Access your browser sandbox from any Tailscale device.

Option 1: Full Setup

Install Ignition + Tailscale together:

curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/full-setup.sh | bash -s -- tskey-YOUR-KEY

Option 2: Add to Existing

If Ignition is already installed:

curl -sL https://raw.githubusercontent.com/teslasolar/ignition-sandbox/main/tailscale-install.sh | bash

After Installation

Connect to your Tailnet:

tailscale up --authkey=tskey-xxx

Then from any Tailscale peer:

http://<tailscale-ip>:8088
How it works
  1. Tailscale runs inside WebVM
  2. Uses userspace networking (WASM compatible)
  3. Joins your Tailnet mesh
  4. Other devices reach Ignition via Tailscale IP

Get Auth Key

Create at: Tailscale Admin Console
